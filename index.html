About

1人で設計から本番運用まで

上場ITコンサルティング企業でのブロックチェーン開発を経て、 現在はフリーランスとして金融機関向けSaaSの開発に参画。 4名チームのバックエンド全域を担い、 20以上のAPIドメイン設計からAzureインフラ構築・運用まで一貫して推進しています。

Azure OpenAI・Speech Serviceを活用したAI機能（音声文字起こし・ ライブ要約・公正証書案文の自動生成）の技術選定からPoC実装まで 単独で完遂。業務支援AIエージェントの設計・実装も手がけています。

個人プロダクトではiOSアプリのApp Store公開、Chrome拡張の Chrome Web Store公開など、実装だけでなくユーザーに届けるところまで 一人で完結させた実績があります。

Claude Code・Cursor・Codexなど最新のAI開発ツールを導入し、 少人数でも大きなスコープをカバーする開発体制を構築しています。
